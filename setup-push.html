Set up reminders when Tally is closed

This page made three secret values just now, inside your browser. Nothing on this page is sent anywhere. Do the three steps below in order, then close this page. Keep this tab open until you finish: if you reload it, it makes new values and you'd start over.

Treat these like passwords. Paste them only into Vercel and Supabase as shown, nowhere else (not in a chat or email).

1Put three values into Vercel

  1. Open vercel.com → your tally project → Settings (top) → Environment Variables (left).
  2. For each row below: click Copy next to the name and paste it in Key, then click Copy next to the value and paste it in Value. Leave All Environments selected and click Save.

Making keys…

When all three are saved, go to Deployments (top), click the ⋯ on the newest one → Redeploy → Redeploy. (Vercel only reads new values on a fresh deploy.)

2Run one block in Supabase

  1. Open supabase.com → your project → SQL Editor (left) → + New query.
  2. Click Copy below, paste into the editor, and click Run. You should see Success.

This creates the tables, stores the timer's secret, and tells Supabase to check for due reminders every minute.

If it says extension "pg_cron" is not available or similar: in Supabase go to Integrations (left) → Cron → Enable, and Integrations → pg_net (or Database → Extensions → pg_net) → Enable. Then click Run again.

3Turn it on in Tally

Close Tally completely and open it again (on each computer and phone). If notifications are already allowed and sync is on, there's nothing else to click. To check: Settings → the notifications line should say “on, even when Tally is closed”.
